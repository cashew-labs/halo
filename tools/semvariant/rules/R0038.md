# Return expected failures with errore and convert exceptions only at external boundaries.

Return expected failures as typed error values and preserve their causes. Convert exceptions at the external call that can throw; do not catch whole application workflows or disguise unexpected bugs as expected failures.

Load the [errore skill](../../../.agents/skills/errore/SKILL.md) for the error-handling patterns, tagged errors, and resource-cleanup workflow.
