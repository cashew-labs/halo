# Search and consolidate existing rules before adding another claim.

Use `pnpm semvariant search <terms>` and read nearby claims before creating a rule. Edit the existing owner when the guidance changes. Merge overlapping rules when they express the same claim, retain a stable surviving ID, delete the retired source, and regenerate guides. Keep distinct claims separate even when they affect the same files.

Record settled, user-authorized guidance rather than speculative preferences or a workaround for one task. Scope it to the directories where it matters, and remove guidance that no longer applies.
