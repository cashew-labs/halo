# Refresh Entire memory through the supervised private worker.

Resume starts the supervised `entire-memory` service. Every five minutes it fetches **only** checkpoint refs from the private repository, updates Brain with `refresh --raw --no-transcript-sweep --agent none` without model calls or transcript-cache deletion, and attempts private hosted memory sync with the current user's Entire login. A failed fetch stops that pass. Uploads cover every stored fact branch, the default branch, and the current branch, so switching branches cannot strand a memory. Only the selected current branch pulls, against its snapshotted commit even if the checkout changes during sync; a missing branch fails before upload. Other branches use `--push-only` to preserve their local stores. Skipped unpublishable memories degrade the receipt. It never backfills or distills sessions through a model automatically. A missing private-repo permission or Entire login degrades memory, not offline capture. Check worker progress with `amp orb service logs entire-memory`; stop it with `amp orb service stop entire-memory`. Outside an orb, run `node .agents/entire.mjs --refresh` on demand.
