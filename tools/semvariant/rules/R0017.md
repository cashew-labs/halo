# Preserve the pinned Brain and Graph builds and generated agent guide.

Setup also installs pinned Graph 0.6.0 and builds Brain 0.4.0 with `.agents/patches/entire-brain.patch` (version `0.4.0+halo.raw`). Brain currently fails to retrieve conversation text from compact checkpoints. The worker uses the supported `--raw` format; the patch exposes Brain's existing cache-preservation option as `--no-transcript-sweep` for unattended refresh, adds `memories sync --push-only` for off-checkout stores, and pins pull visibility to the selected branch's commit before network calls. Do not replace it until conversation retrieval, cache preservation, and memory preservation across checkout changes pass. The generated `.entire/agent-guide.md` covers both tools; do not edit it by hand. To regenerate it, run `entire graph setup --repo . --no-claude-hook`, then `entire brain setup --strict --no-backfill --no-daemon --no-agent-hooks --agent none`. Preserve instructions outside the managed markers. Never run Brain setup, checkpoint fetches, hosted login, or memory sync during shared orb setup: private data and credentials belong only in the running orb, not its shared snapshot.

After regenerating the Entire guide, run `pnpm semvariant generate` and `pnpm semvariant check` to restore the semvariant-owned title indexes if Entire added a managed activation block to `AGENTS.md`. R0018 retains the instruction to read `.entire/agent-guide.md`; semvariant owns the root projection.
