# Keep one authoritative rule source and generate every AGENTS.md projection.

Author rules as `RNNNN.md` in `tools/semvariant/rules/`. Each has YAML frontmatter containing only a nonempty, duplicate-free `guides` list of existing repository directories, followed by exactly one H1 title and its full body. Use `.` for repository-wide guidance. IDs are stable identities, not priorities; use the next unused ID when adding a rule.

`pnpm semvariant generate` projects each title into the `AGENTS.md` files named by its guides. It repairs missing or changed generated guides and deletes stale generator-owned guides. It refuses to overwrite authored guides. Do not hand-edit generated guides or retain a parallel conventions handbook. Keep a rule near its conceptual owner by choosing its guide scope; all canonical rule files live together for CLI retrieval.

After editing, merging, retiring, or re-scoping rules, run `pnpm semvariant generate` followed by `pnpm semvariant check`. The check is part of `pnpm check-affected`. Retrieval commands also reject stale projections.
