# Research dependency behavior before adding integration wrappers or defensive ceremony.

Research established behavior before adding surprising ceremony around an external dependency. If straightforward code appears to need guards, wrappers, assertions, retries, or compatibility logic, inspect the dependency's source, official documentation, and relevant GitHub issues before keeping that design.

For common integrations, compare relevant established implementations as evidence for ownership and lifecycle decisions. Keep Halo’s own ownership, error-handling, and package boundaries when another project’s design differs.
