# Use Halo’s names for symbols, files, folders, and identifier values.

Use PascalCase for classes, types, interfaces, enums, and React components. Use camelCase for functions and values. Name a file after its primary export with the same casing and no hyphens; tests mirror the implementation file's name. When a module has no single primary export, name it after the shared concept in camelCase, or use one lowercase word when the folder provides enough context. Use one lowercase word for folders when practical, organize services with their domain helpers, and retain framework-required names. TypeScript ESM imports use `.js` extensions. Native Node type-stripped tooling uses explicit `.ts` imports because Node runs those source files directly.

Name variables and parameters that hold identifiers with an entity-specific `Id` suffix, such as `threadId` or `readCursorId`. Avoid ambiguous identifier names such as `thread`, `cursor`, `result`, or bare `id` when the value is specifically an identifier and a clearer entity name is available.
