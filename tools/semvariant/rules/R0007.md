# Load the Diffmap comparison skill for explicitly requested viewer comparisons.

When the user requests a comparison of the two Diffmap presentations, load the [diffmap-compare skill](../../../.agents/skills/diffmap-compare/SKILL.md). It owns preparation, authoring, launching, and verification for that comparison. Do not apply the comparison workflow to ordinary spec or walkthrough requests.

Use the repository scripts in `package.json` to serve specs and walkthroughs; keep command definitions at that source.
