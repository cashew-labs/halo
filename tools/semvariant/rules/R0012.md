# Validate completed changes through their actual consumer surface.

Validate completed changes through the actual consumer surface whenever reasonable, in addition to focused automated checks. For UI and interaction changes, load the [halo-app skill](../../../.agents/skills/halo-app/SKILL.md), exercise the affected flow in the running app, and inspect a screenshot when layout matters. If live validation is impractical, state why.
